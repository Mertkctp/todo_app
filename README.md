# FocusFlow v3 - Modern Productivity Workspace

Bu proje, React ve Tailwind CSS kullanılarak geliştirilmiş kapsamlı bir üretkenlik asistanıdır.

## 🚀 Canlı Demo
[https://mertkocatepetodo.netlify.app/]

## ✨ Özellikler
- **Görev Takvimi:** LocalStorage destekli, tarih etiketli yapılacaklar listesi.
- **Pomodoro Sayacı:** 25 dakikalık özelleştirilebilir tur seçimli (25x1, 25x2...) sayaç.
- **Hızlı Notlar:** Otomatik kaydedilen kişisel not alanı.
- **Motivasyon Bölümü:** Her açılışta değişen dinamik motivasyon sözleri.
- **Dark/Light Mode:** Göz yormayan karanlık mod desteği.

## 🛠️ Kullanılan Teknolojiler
- React.js (Vite)
- Tailwind CSS
- Lucide Icons
- LocalStorage API
